# 进游戏怎么测（10 分钟走完一条产线）

## 0. 前置

服务器启动日志里应该有这几行（`logs/latest.log`）：

```
[CeBotania] 配方 218 条（花药台 43 / 灌注 158 / 符文 17），标签 61 组
[CeBotania] [自检] 摆件于 (96,64,96)：花药台=true 花=true 发射器=true 池子=true
[CeBotania] [自检 15s] 花=0(tick 48) 发射器=600 池子=600
```

最后一行是关键 —— **发射器和池子的数字不为 0，说明魔力管线通了**。
如果池子是 0，先看 `docs/troubleshooting.md`。

## 1. 拿花瓣

两种方式：

- **找神秘花**：新生成的区块里，草方块上会零散长出 16 色神秘花，打掉得 2~3 个同色花瓣。
- **打原版花**：蒲公英→黄色、虞美人→红色、兰花→淡蓝……矮草和蕨也掉（黄绿/绿色）。

找不到就用命令：

```
/botania give white_petal 8
/botania give lime_petal 8
/botania give wheat_seeds 4
```

## 2. 花药台做花

1. 放一个**花药台**（`apothecary_default`）：`/botania give apothecary_default`
2. **手持水桶右键**注水
3. **手持花瓣/种子右键**逐个投入 —— 每投一次屏幕上会显示已投几样
4. 凑齐配方后，台子上方会长出花

第一朵花建议做**萤火之焰**（Endoflame）：查配方

```
/botania recipe endoflame
```

或者直接看 `pack/configuration/recipes/petal_apothecary.json` 里
`botania:petal_apothecary/endoflame` 那一条（棕色花瓣 ×2 + 任意种子）。

## 3. 接上产线

按顺序摆（相邻即可）：

```
[花药台] [萤火之焰] [魔力发射器] [魔力池]
```

- 往萤火之焰旁边**丢一块煤**（Q 键），它会吃掉并开始产魔
- 右键花 → 显示它当前攒了多少魔力
- 右键发射器 → 显示缓存
- 右键池子 → 显示 `魔力池 xxx / 1,000,000`

**池子数字开始涨 = 整条链路通了。**

## 4. 灌注

池子里有魔力后，**手持铁锭右键魔力池** → 变成魔力钢锭（消耗 3000 mana）。

其他常用：

| 投入 | 产出 | 魔力 |
|---|---|---|
| 铁锭 | 魔力钢锭 | 3000 |
| 钻石 | 魔力钻石 | 10000 |
| 末影珍珠 | 魔力珍珠 | 6000 |
| 下界石英 | 魔力石英 | 1000 |
| 煤炭 | 魔力粉尘 | 500 |

查某样东西要多少：

```
/botania recipe botania:manasteel_ingot
```

## 5. 一键自检（不想手动摆）

```
/botania demo ~ ~ ~
```

会在你脚下摆好一套产线并丢好煤，15 秒内池子应该开始涨。
读数字用：

```
/botania inspect <x> <y> <z>
```

## 外观/碰撞是否正确

这几条是重点验证项：

| 检查 | 期望 |
|---|---|
| 花能不能走过去 | 能，直接穿过（0 碰撞） |
| 花下方方块的顶面 | 正常显示，没有"透明天花板" |
| 魔力池/发射器/花药台 | 能站上去（半格高），不是悬空也不是满块 |
| 花的外观 | 十字交叉的花模型，和原版 Botania 一样 |
| 池子外观 | 池子模型，不是台阶 |

如果哪条不对，把现象记到 `docs/troubleshooting.md` 的"待修"里。
