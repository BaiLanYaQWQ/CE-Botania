## 这是什么

Botania（植物魔法）是 Minecraft 最经典的魔法向 mod 之一。这个项目把它的玩法**移植到了插件服**端：

- 服务端是 **Paper / Leaves**（不需要 Forge / Fabric）
- 客户端**不需要装 mod**，只接受一个资源包
- 方块、物品、模型、贴图全部通过 **CraftEngine** 实现

目标是把「野花 → 花瓣 → 花药台 → 产魔花 → 魔力 → 符文 → 装备」这条完整主线做到能玩。

## 已实现的功能

### 花与花药台

- **16 色神秘花**世界生成
- 打花掉 2~3 个同色花瓣，剪刀可采整朵
- **花药台**：注水 → 投料 → 产物掉落，**44 条配方**（一种花药台可做全部花）
- **产魔花 10 种**，火红莲改为**持续燃烧**（一块煤 40 秒产 800 魔力）
- **功能花 20 种**，消耗与间隔对齐上游：
  - 农业花、落樱、紫颂花、漏斗花、熔炉花、钟兰、恐惧荆棘
  - 毒酸花、迟缓花、虎眼石、矿石花、下界矿石花、播种花
  - 粘土花、风车花、繁殖花、浮空花、缠绕花、催眠花、大理石花
  - 弱磁兰、诱引莲、凌空蓟、聚宝花、消音柑

### 魔力系统

- **魔力发射器**：6 个朝向（含上/下）、16 格探测、**接力传输**、可贴池抽取
- **4 种发射器变体**：普通 / 精灵（快 25%）/ 盖亚（容量 6.4 倍）/ 红石（需信号）
- **火花系统**：装在池子/祭坛/凝聚板上，**16 格圆形接力**，只在真正搬运时出粒子

### 仪式与合成

- **魔力灌注 158 条**：铁→魔钢、钻石→魔力钻石、珍珠→魔力珍珠…
- **符文祭坛 17 条**，按上游 4 步流程：
  1. 投配方材料
  2. 魔力自动注入
  3. 魔力满了放活石
  4. 森林法杖点火
- **纯洁雏菊**：3×3×1 区域转换（石头→活石、原木→活木…）

### 泰拉钢线

- **泰拉凝聚板**：5 活石 + 4 青金石的棋盘结构
- 投入魔钢锭 + 魔力钻石 + 魔力珍珠，经火花供魔后成型
- **三件泰拉工具**：
  - **泰拉粉碎者**：潜行一次挖 3×3×3
  - **泰拉断裂者**：连锁砍倒整棵树
  - **泰拉之刃**：右键发射剑气（12 格，9 点伤害）
- 数值对齐上游：耐久 2300 / 附魔 26 / 挖掘速度 9.0

### 精灵传送门

- **官方 5×5 框架**（11 块活木，四角空），**东西/南北双朝向**都支持
- 周围 5 格内需要 **2 组「魔力池 + 上方自然水晶」**
- 森林法杖开关，开门扣 20 万魔力，**开启后持续耗魔约 500/s**
- 中间 3×3 生成**绿色 32 帧动画通道**
- **往通道里丢物品**即可与精灵交易（14 条配方，含标签类）

### 其他

- **魔法水晶**：增强原版附魔台，**2 个魔法水晶 = 30 级附魔**
- 天然水晶 15 / 盖亚水晶 15 等效书架
- **魔钢装备**：耐久消耗魔力抵消，物品栏显示剩余魔力
- **植物魔法辞典**：990+ 页全中文，含配方、摆法、实现状态标注

## 安装

### 环境要求

```
服务端：Paper 26.3 或 Leaves 26.3
前置插件：CraftEngine 26.9.2
客户端：Minecraft 26.3（只要资源包，不装 mod）
Java：25
```

### 安装或升级到 1.0.0

1. 下载并解压总包 `CE-Botania-1.0.0.zip`。停服，备份世界和现有 CraftEngine 包。
2. 安装 CraftEngine 26.9.2，将旧版 CeBotania JAR 移出插件目录，把 `CE-植物魔法-1.0.0.jar` 放入 `plugins/`。
3. 将旧的 Botania 包移至备份位置，把内层 `CE-Botania-pack.zip` 解压到 `plugins/CraftEngine/resources/botania/`。打开这个目录应直接看到 `pack.yml`、`configuration/`、`resourcepack/` 和 `blueprint/`。
4. 在 CraftEngine 的 `config.yml` 设置 `misc.delay-configuration-load: true`。测试服使用 `block.serverside-blocks: 18000`，同服加载其他包时需额外预留容量。
5. 启动服务器，让玩家接受更新的资源包。

## 命令

| 命令 | 说明 |
|---|---|
| `/botania selfcheck` | 自检（方块/物品/配方数量） |
| `/botania give <物品>` | 给自己一个自定义物品 |
| `/botania place <方块> <x> <y> <z>` | 放置一个自定义方块 |
| `/botania inspect <x> <y> <z>` | 查看方块状态（魔力/朝向/配方） |
| `/botania manaset <x> <y> <z> <数量>` | 设置魔力池魔力 |
| `/botania rotate <x> <y> <z>` | 旋转发射器朝向 |

> 命令必须用完整的 `/botania`。`/bot` 是 Leaves 的假人命令，不要用简写。

## 玩法提示

### 开局

1. 在草地上找**神秘花**（16 种颜色）
2. 打掉得到**花瓣**
3. 用 **8 个原石 + 1 个花瓣** 在工作台合成**花药台**
4. 花药台**注水**（手持水桶右键）
5. 往里投花瓣，做出**产魔花**

### 产魔与传输

1. 产魔花旁边放**魔力发射器**（默认朝北，用森林法杖右键旋转）
2. 发射器要**对准**魔力池的方向
3. 发射器会自动从附近的花吸魔力，攒满后发射

### 符文

1. 花药台做出**符文祭坛**
2. 投配方材料
3. 用发射器或火花往祭坛灌魔力
4. 魔力满了放**活石**
5. 森林法杖点火

### 泰拉钢

1. 3×3 放**5 个活石（四角+中心）+ 4 个青金石（四边中点）**
2. 中心上方放**泰拉凝聚板**
3. 给凝聚板和魔力池**各装一个火花**
4. 往板上丢魔钢锭 + 魔力钻石 + 魔力珍珠
5. 右键凝聚板成型

## 已知限制

### 还没做的

- **盖亚守护者（Boss 战）**——主线终局内容
- **部分功能方块的精确碰撞**——花药台和符文祭坛仍使用满格碰撞
- **精灵实体**——交易目前是直接交换，没有精灵飞出来
- **Corporea 物流网络**——物品管道系统
- **植物酿造**——20+ 种药水

### 简化实现的地方

| 项 | 上游 | 本移植版 |
|---|---|---|
| 消音柑 | 真正消除声音 | 近似实现（插件端无法拦截客户端声音） |
| 诱引莲 | 拦截末影人传送 | 把末影人往花心拽 |
| 聚宝花 | 刷带战利品的怪 | 刷普通怪 |
| 凌空蓟 | 传送到指定目标 | 传进最近的容器 |
| 精灵门 | 需要 4 个信标 + 复杂仪式 | 5×5 活木框架即可 |

## 常见问题

**Q：方块没模型 / 黑紫**

A：清 `plugins/CraftEngine/cache/*.json` 和 `*.bin`，重启，客户端完全重进。

**Q：资源包提示损坏**

A：确认解压到 `resources/botania/` 而不是 `resources/botania/pack/`。

**Q：某个方块放下后没有碰撞**

A：1.0.0 已修复盆栽、台阶、楼梯、玻璃板、墙、栅栏和栅栏门。魔力池服务端采用内凹池形，发射器采用居中小方块；原版客户端对这两类仍按整格预测。反馈时请附方块名、朝向及相邻方块。

**Q：精灵门薄片方向不对**

A：先关门再开门。薄片方向是开门时按框架朝向决定的。

**Q：`/bot` 命令不生效**

A：用 `/botania`。`/bot` 是 Leaves 的假人命令。
