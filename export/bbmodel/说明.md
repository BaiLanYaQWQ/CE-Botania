# Botania 盔甲 · Blockbench 工程

## 文件

| 文件 | 对应 Botania 类 | 方块数 | 骨骼数 |
|---|---|---|---|
| `manasteel_armor.bbmodel`  | ManasteelArmorModel  | 18 | 28 |
| `elementium_armor.bbmodel` | ElementiumArmorModel | 17 | 35 |
| `terrasteel_armor.bbmodel` | TerrasteelArmorModel | 33 | 43 |
| `manaweave_armor.bbmodel`  | ManaweaveRobeModel   | 13 | 23 |
| `textures/`                | 上游 64×128 盔甲贴图 | | |

## 在 Blockbench 里打开

1. Blockbench → **File → Open Model**
2. 选 `manasteel_armor.bbmodel`
3. 左侧 **Textures** 面板 → 点贴图 → **Replace Texture**，选
   `textures/armor_manasteel.png`
4. 右上角切到 **Display** 标签，能看到 `head` / `thirdperson_righthand` 这些预设

## 骨骼结构（和 Minecraft 模型一致）

```
head
└── helm
    ├── helm_top          顶部前伸的角
    └── helm_crystal      前额水晶
body
├── belt                  腰带
└── body_top              胸甲
    └── body_bottom       腰裙
left_arm / right_arm
└── left_arm_main
    ├── left_arm_pauldron 肩甲
    └── left_arm_crystal  肩部水晶
left_leg / right_leg
└── *_leg_crystal         踝部水晶
```

## 坐标说明

- 坐标系：**y 向上**（已经从 Minecraft 的 y 向下翻转过了）
- 原点：脖子位置（相当于玩家模型 `head` 的枢轴）
- 尺寸单位：像素（16 = 1 格），和 Minecraft 原版一致
- UV：按上游 `texOffs` 值，对应 64×128 的贴图
