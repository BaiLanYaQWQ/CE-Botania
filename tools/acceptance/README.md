# CeBotania 测试服验收

在仓库根目录使用 Python 3 和 JDK 25 运行：

```bash
python3 tools/acceptance/run.py
```

默认使用本机已初始化且已接受 EULA 的 `Server/` 作为模板。干净检出可用 `--server-template /绝对路径/Server` 指向现有 Leaves 26.3、CraftEngine 26.9.2 测试服。模板需包含服务端 JAR、运行库、缓存，以及已启用延迟配置加载的 CraftEngine 配置和基础资源。已有完整 Gradle 缓存时可以加 `--offline`。

脚本构建生产插件和独立探针，在临时目录启动一份使用当前仓库资源包的测试服。它创建固定种子的平坦主世界，以本机回环地址监听，使用控制台执行 `ceaccept`。探针在测试世界放置真实方块和掉落物，检查两种朝向的精灵门、门外物品、新区块自然生成的神秘花，以及火花跨区块的距离边界和卸载重载后的魔力传输。精灵门开启通过生产代码完成，玩家手持法杖的交互需要另行实测。

终端显示各场景结果。成功返回 0，失败或超时返回非零。每次运行的完整日志和生产插件 SHA-256 保存在 `plugin/build/acceptance/run-*/`，服务端退出后清理临时世界。
